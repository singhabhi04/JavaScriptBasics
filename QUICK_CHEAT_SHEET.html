📦Variables & Types

Variable Declaration

const x = 5;      // immutable
let y = 10;       // mutable, block-scoped
var z = 15;       // avoid (old)

Data Types

typeof 42         // "number"
typeof "text"     // "string"
typeof true       // "boolean"
typeof undefined  // "undefined"
typeof null       // "object" (BUG!)

➕Operators

Comparison

5 === "5"    // false (strict)
5 == "5"     // true (loose)
5 != 5       // false
5 !== "5"    // true

Logical

true && false   // false
true || false   // true
!true           // false

// Ternary
age >= 18 ? "Adult" : "Minor"

📋Array Methods - Quick Ref

Mutating Methods (Change Original)

arr.push(4)          // Add to end
arr.pop()            // Remove from end
arr.unshift(0)       // Add to start
arr.shift()          // Remove from start
arr.splice(1, 1)     // Remove/add at index
arr.reverse()        // Reverse array
arr.sort((a,b) => a-b) // Sort

Non-Mutating Methods (Return New Array)

arr.slice(1, 3)         // Extract: [2,3]
arr.map(x => x*2)       // Transform: [2,4,6]
arr.filter(x => x>1)    // Keep: [2,3]
arr.find(x => x>2)      // First match: 3
arr.reduce((a,x) => a+x, 0) // Sum: 6
arr.concat([4,5])       // Combine
arr.join("-")           // To string: "1-2-3"

Array Search

arr.includes(2)         // Check: true
arr.indexOf(2)          // Index: 1
arr.findIndex(x => x>2) // Index: 2

📝Strings

String Methods

str.length             // 5
str.charAt(0)          // "H"
str.toUpperCase()      // "HELLO"
str.toLowerCase()      // "hello"
str.includes("ell")    // true
str.indexOf("l")       // 2
str.slice(0, 3)        // "Hel"
str.trim()             // Remove whitespace
str.split("")          // To array
str.replace("l", "L")  // "HeLlo" (first)
str.repeat(3)          // "HhhHhhHhh"

// Template literal
`Hello ${name}`        // String interpolation

⚙️Functions

Declaration Styles

// Declaration
function add(a, b) { return a + b; }

// Expression
const add = function(a, b) { return a + b; };

// Arrow (ES6)
const add = (a, b) => a + b;
const square = x => x * x;

Callbacks & HOF

// Callback
function execute(fn) { return fn(); }
execute(() => 42);

// HOF returning function
const makeAdder = n => x => x + n;
const add5 = makeAdder(5);
add5(10); // 15

// Closure
function counter() {
    let count = 0;
    return () => ++count;
}

🔀Control Flow

Conditionals & Loops

// if/else/switch
if (x > 5) { } else if (x < 0) { } else { }
switch (x) { case 1: break; default: }

// Loops
for (let i = 0; i < 10; i++) { }
for (const item of array) { }
array.forEach(item => { })
while (condition) { }

❌Falsy Values (IMPORTANT!)

Value Type Check Example
false Boolean Falsy if (!false) ✓
0 Number Falsy if (!0) ✓
"" String Falsy if (!"") ✓
null Special Falsy if (!null) ✓
undefined Special Falsy if (!undefined) ✓
NaN Number Falsy if (!NaN) ✓

Remember: Everything else is TRUTHY (1, "text", [], {}, true, etc.)

✅❌Do's and Don'ts

✅ Do

Use === instead of ==
Use const by default
Use arrow functions =>
Use map(), filter(), reduce()
Use template literals with backticks
Use array methods for loops

❌ Don't

Don't use == for comparison
Don't forget break in switch
Don't confuse slice() and splice()
Don't assume sort() works on numbers
Don't nest callbacks too deeply
Don't use var (old style)

⚠️Common Mistakes

Sorting Numbers

// ❌ WRONG
[10, 5, 100, 2].sort() // [10, 100, 2, 5]

// ✅ CORRECT
[10, 5, 100, 2].sort((a,b) => a-b) // [2, 5, 10, 100]

slice() vs splice()

arr.slice(1, 3)   // Non-mutating: returns new array
arr.splice(1, 3)  // Mutating: modifies original

typeof Quirks

typeof null       // "object" ❌ Use === null
typeof []         // "object" (use Array.isArray())
typeof NaN        // "number" (use Number.isNaN())
NaN === NaN       // false (always compare with isNaN)

🎯Common Patterns

Remove Duplicates

const unique = [...new Set(arr)];

Sum Array

const sum = arr.reduce((a, x) => a + x, 0);

Transform & Filter Chain

arr
    .filter(x => x > 0)
    .map(x => x * 2)
    .reduce((sum, x) => sum + x, 0)

Default Values

const x = value || 10;           // OR operator
const y = value ?? 10;           // Nullish coalescing
