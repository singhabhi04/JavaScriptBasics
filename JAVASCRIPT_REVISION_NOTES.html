1️⃣ JavaScript Basics

Primitive Data Types

JavaScript has 7 primitive data types that cannot be changed once created:

// String
let name = "Abhishek Singh";
console.log(typeof name); // "string"

// Number (int or float)
let age = 35;
let price = 99.99;
console.log(typeof age); // "number"

// Boolean
let isMarried = true;
console.log(typeof isMarried); // "boolean"

// Undefined - variable declared but not assigned
let lastname;
console.log(lastname); // undefined
console.log(typeof lastname); // "undefined"

// Null - represents intentional absence of value
let webdriver = null;
console.log(typeof webdriver); // "object" (bug in JS!)
Key Points:
  • undefined = declared but not assigned
  • null = intentional empty value
  • typeof operator checks data type
  • typeof null returns "object" (known JS quirk)

Type Conversion

Explicit Type Conversion:

// String Conversion
String(123);           // "123"
String(true);          // "true"

// Number Conversion
Number("42");          // 42
Number(true);          // 1
Number(false);         // 0

// Boolean Conversion
Boolean(1);            // true
Boolean(0);            // false
Boolean("");           // false

Type Coercion (Implicit Conversion):

// String Coercion (+ operator)
console.log("5" + 2);      // "52" (concatenation)
console.log(2 + 1 + "5");  // "35" (math first, then concat)

// Numeric Coercion (-, *, /, %)
console.log("10" - 2);     // 8
console.log("10" * 2);     // 20

Equality Operations

// Loose Equality (==) - COERCES types
console.log(5 == "5");      // true
console.log(0 == false);    // true

// Strict Equality (===) - NO coercion
console.log(5 === "5");     // false
console.log(0 === false);   // false

// ✅ BEST PRACTICE: Always use ===
Falsy vs Truthy:
8 Falsy Values: false, 0, -0, 0n, "", null, undefined, NaN
Everything else is Truthy

2️⃣ Loops & Conditionals

Conditional Statements

// if/else if/else
if (age <= 18) {
    console.log("Child");
} else if (age < 60) {
    console.log("Adult");
} else {
    console.log("Senior");
}

// switch/case
switch (day) {
    case "Mon":
        console.log("Monday");
        break; // Don't forget break!
    default:
        console.log("Unknown");
}

// Ternary operator
age >= 18 ? "Adult" : "Minor"

Loops

// for loop
for (let i = 0; i < 5; i++) {
    console.log(i);
}

// for...of loop (iterate VALUES)
for (const fruit of fruits) {
    console.log(fruit);
}

// forEach loop
fruits.forEach((fruit, index) => {
    console.log(index, fruit);
});

// while loop
while (i < 10) {
    console.log(i);
    i++;
}
Loop Comparison:
  • for - Classic loop with index
  • for...of - Iterate array values (not indexes)
  • forEach - Pass callback for each element
  • while - Loop while condition is true

3️⃣ Arrays & Array Methods

Array Basics

const arr = [10, 20, 30];
console.log(arr.length);    // 3
console.log(arr[0]);        // 10
console.log(arr.at(-1));    // 30 (last element)

Array Methods Quick Reference

Method Mutates? Returns Use Case
push() ✅ Yes New length Add to end
pop() ✅ Yes Removed element Remove from end
shift() ✅ Yes Removed element Remove from start
slice() ❌ No New array Extract portion
map() ❌ No New array Transform elements
filter() ❌ No New array Keep matching
reduce() ❌ No Single value Accumulate
sort() ✅ Yes Sorted array Sort elements

Transformation Methods

// map() - Transform each element
const numbers = [1, 2, 3];
const doubled = numbers.map(x => x * 2);
console.log(doubled); // [2, 4, 6]

// filter() - Keep matching elements
const large = numbers.filter(x => x > 1);
console.log(large); // [2, 3]

// reduce() - Accumulate to single value
const sum = numbers.reduce((acc, x) => acc + x, 0);
console.log(sum); // 6

Sorting Arrays

const numbers = [10, 5, 100, 2];

// ❌ WRONG: Default alphabetical sort
numbers.sort(); // [10, 100, 2, 5]

// ✅ CORRECT: Ascending numeric sort
numbers.sort((a, b) => a - b); // [2, 5, 10, 100]

// Descending numeric sort
numbers.sort((a, b) => b - a); // [100, 10, 5, 2]

5️⃣ Functions & Advanced Concepts

Function Declaration Styles

// Function Declaration
function add(a, b) {
    return a + b;
}

// Function Expression
const subtract = function(a, b) {
    return a - b;
};

// Arrow Function (ES6)
const multiply = (a, b) => a * b;

// Single parameter (optional parentheses)
const square = x => x * x;

// No parameters
const random = () => Math.random();

Callbacks

A callback is a function passed to another function, executed later:

// Simple callback
function handleCompletion(callback) {
    console.log("Work done!");
    callback("Success");
}

// Asynchronous callback
function fetchUser(userId, callback) {
    setTimeout(() => {
        const user = { id: userId, name: "Abhishek" };
        callback(user);
    }, 2000);
}

fetchUser(1, (user) => {
    console.log("User:", user);
});

Higher-Order Functions

A function that takes another function or returns a function:

// HOF that takes a function
function calculate(a, b, operation) {
    return operation(a, b);
}

calculate(10, 5, (x, y) => x + y); // 15
calculate(10, 5, (x, y) => x - y); // 5

// HOF that returns a function
function createDiscount(percent) {
    return function(price) {
        return price - (price * percent / 100);
    };
}

const tenOff = createDiscount(10);
console.log(tenOff(100)); // 90

Closures

A function remembers variables from its outer scope:

function makeCounter() {
    let count = 0;
    
    return function() {
        count++;
        return count;
    };
}

const counter = makeCounter();
console.log(counter()); // 1
console.log(counter()); // 2
console.log(counter()); // 3

// Each counter has its own closure
const counter2 = makeCounter();
console.log(counter2()); // 1

6️⃣ Practice Problems

Problem 1: Sum Array Using Reduce

const numbers = [1, 2, 3, 4, 5];
const sum = numbers.reduce((acc, val) => acc + val, 0);
console.log(sum); // 15

Problem 2: Extract Initials

const names = ['Abhishek', 'Kumar', 'Singh'];
const initials = names.map(n => n[0]).join("");
console.log(initials); // "AKS"

Problem 3: Reverse a Number

let num = 12345;
let reversed = 0;
while (num > 0) {
    reversed = reversed * 10 + (num % 10);
    num = Math.floor(num / 10);
}
console.log(reversed); // 54321

Problem 4: Filter and Transform

const transactions = [100, -50, 200, -75];
const debits = transactions
    .filter(t => t < 0)
    .map(t => ({ amount: Math.abs(t), type: "Debit" }));
console.log(debits);

7️⃣ Quick Reference

Do's

✅ Use === instead of ==
✅ Use const by default, let when reassignment needed
✅ Use map(), filter(), reduce() for array operations
✅ Use template literals with backticks
✅ Use arrow functions for conciseness

Don'ts

❌ Don't forget break in switch statements
❌ Don't mix up slice() and splice()
❌ Don't use == for comparisons
❌ Don't assume sort() works on numbers
❌ Don't nest callbacks too deeply

Falsy Values (IMPORTANT!)

false       // boolean false
0           // number zero
-0          // negative zero
0n          // BigInt zero
""          // empty string
null        // intentional empty
undefined   // no value
NaN         // not a number

// REMEMBER: Everything else is TRUTHY!

Common Mistakes

// ❌ WRONG: Sorting numbers as strings
[10, 5, 100, 2].sort(); // [10, 100, 2, 5]

// ✅ CORRECT: Use comparator
[10, 5, 100, 2].sort((a,b) => a-b); // [2, 5, 10, 100]

// ❌ WRONG: Confusing slice and splice
arr.slice(1, 3);   // Non-mutating, returns new array
arr.splice(1, 3);  // Mutating, modifies original

// ✅ CORRECT: Always use ===
if (x === 5) { }   // Good
if (x == 5) { }    // Bad

// ❌ typeof null returns "object" (bug!)
typeof null // "object"
x === null  // Correct way to check
